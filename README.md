# 🎬 PrimeApp – Filmes em Cartaz

Aplicação web desenvolvida em React que consome a API do The Movie Database (TMDB) para exibir filmes em cartaz no cinema.

## 🚀 Funcionalidades
- Listagem de filmes em cartaz
- Visualização de detalhes do filme
- Acesso ao trailer
- Salvar e remover filmes favoritos
- Navegação entre páginas com React Router

## 🛠 Tecnologias Utilizadas
- React.js
- JavaScript (ES6+)
- API REST (TMDB)
- HTML5
- CSS3
